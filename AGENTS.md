# Projeto: agendamento online com lembrete no WhatsApp

## Stack
- Python 3.12 + Django
- PostgreSQL (SQLite em desenvolvimento)
- Templates Django + Tailwind CSS + HTMX
- Lembretes via comando Django rodando em cron

## Regras
- Código e nomes de variáveis/modelos em português (ex: Agendamento, Servico)
- Fuso horário sempre America/Sao_Paulo (USE_TZ = True)
- Toda lógica de horários livres precisa de testes
- Nunca commitar segredos; usar .env
- Mudanças pequenas e focadas: uma funcionalidade por vez
- Explique o que mudou ao final de cada tarefa
